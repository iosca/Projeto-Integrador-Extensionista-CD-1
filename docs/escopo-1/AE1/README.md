    Tema: Transição Open-Source na Administração Pública de Assis-SP
    Ano: 2026

    Sobre o Projeto (AE1)
      Este repositório armazena a documentação e o planejamento inicial (Atividade de Estudo 1) do projeto extensionista focado na viabilidade técnica e financeira da migração das estações de trabalho administrativas da Prefeitura de Assis-SP para um ecossistema open-source (ex.: Linux Mint, LibreOffice).

    O projeto utiliza dados abertos extraídos do Portal da Transparência municipal (Sistema SCPI Fiorilli) e da Lei Orçamentária Anual (LOA) para embasar as projeções financeiras, visando a otimização dos recursos públicos e a promoção da soberania tecnológica local.

    Objetivos do Escopo 1
      Mapeamento: Levantamento de dados orçamentários de TI via Portal da Transparência.
      Análise: Cálculo do Custo de Licenciamento por Usuário (CLU) atual.
      Projeção: Estimativa de economia (ROI) baseada na substituição de licenças proprietárias.

  Aspectos Éticos e LGPD
    O projeto utiliza exclusivamente dados de domínio público (Lei de Acesso à Informação).Todo o tratamento de perfis de uso de servidores será feito de forma agregada e anonimizada, sem coleta de dados pessoais (CPF, nomes ou IPs), garantindo total conformidade com a LGPD.
