# 4. MATRIZ DE RISCOS

| Risco Mapeado | Probabilidade | Impacto | Ação de Mitigação |
| :--- | :--- | :--- | :--- |
| **1. Inconsistência ou dados ocultos no Portal da Transparência** | Média | Alto | Utilizar os macro-dados da LOA ou solicitar dados complementares ativamente via e-SIC (Lei de Acesso à Informação). |
| **2. Dificuldade de estabelecer a taxa real de uso de softwares** | Alta | Médio | Assumir uma premissa conservadora baseada em benchmarking de outros municípios brasileiros que realizaram migrações similares. |
| **3. Resistência cultural do leitor à usabilidade do Linux** | Alta | Médio | Focar o projeto na métrica financeira (ROI) e incluir capturas de tela demonstrando a familiaridade visual de interfaces como o Linux Mint. |
| **4. Bases de dados brutas despadronizadas ou corrompidas** | Média | Alto | Alocar a Semana 3 do cronograma estritamente para o tratamento rigoroso, limpeza e padronização (ETL) das planilhas CSV. |
| **5. Escopo excessivamente amplo causando atrasos** | Baixa | Médio | Limitar a análise a uma secretaria ou departamento específico (Ex: Secretaria de Administração) caso os dados globais da prefeitura sejam massivos demais para o prazo. |
